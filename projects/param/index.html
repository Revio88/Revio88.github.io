Configuratore per cambio formati Change Parts configurator

Attività Activity

Definizione di un sistema per la realizzazione, in modalità semiautomatica, dei modelli 3D e delle tavole delle attrezzature per il cambio formati.

Definition of a system for the automatic generation of 3D models and drafts for format change parts.

Caratteristiche Features

Gli step seguiti per generazione dei file è stasuddivisa in più step, a partire da un file excel di input, che contiene le regole e le variabili, fino alla generazione dei file utilizzati come modelli.

The steps followed for file generation are divided into several steps, starting from an input Excel file, which contains the rules and variables, up to the generation of the files used as models.

  • Scomposizione della macchina in sottomoduli
  • Subdivision of the machine into submodules
  • Definizione dei limiti di macchinabilità
  • Definition of machineability limits
  • Definizione regole altezze e giochi
  • Definition of rules for heights and clearances

Alla lista di regole sulle altezze ed in giochi è stata aggiunta una tabella di controllo che, a partire dai dati di input, restituisce una lista di check, al fine di evidenziare criticità progettuali.

A control table was added to the list of rules on heights and clearances that, starting from the input data, returns a list of checks, in order to highlight design criticalities.

Tramite delle tabelle di appoggio vengono poi restituite una lista di celle con all'interno i valori che vengono utilizzate come variabili all'interno dei file di solidedge per la generazione delle matematiche.

Using support tables, a list of cells with the values inside is then returned, which are used as variables within the Solid Edge files for the generation of the 3D models.
